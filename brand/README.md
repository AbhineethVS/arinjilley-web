# arinjilley? brand

The logo is a **split-flap tile** (a departure-board flap, like the site's flip clock and the boarding-pass posters) showing a question mark whose dot is a **lime text cursor** (hackathons, code). "arinjilley?" is Malayalam for "didn't you know?": the club tells people about hackathons they'd otherwise miss.

| File | Use |
|---|---|
| `logo-mark.svg` | The app icon / mark on its dark rounded square (source of all icons) |
| `logo-tile.svg` | The mark without a background (used inline next to the name on the site) |
| `avatar-640.png` | Profile picture for the Telegram bot and the WhatsApp group (safe for circular crops) |
| `lockup-dark.png`, `lockup-light.png` | Mark + "arinjilley?" wordmark, for slides, posts, banners |

Colours: background `#161618`, tile `#2A2A2F` / `#202024`, ink `#F2F2F3`, lime `#C8F560` (on light backgrounds use `#5E7A12` for the "?").
Wordmark: Sentient Medium (Fontshare), with the "?" in the accent colour.

App icons in `apps/web/public/icons/` and `apps/web/public/favicon.svg` are generated from `logo-mark.svg`.
